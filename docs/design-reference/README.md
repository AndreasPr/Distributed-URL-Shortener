# Design reference only — not shipped

Google AI Studio generated this Vite/React Router prototype. It is an inert design reference, not the Next.js application. Do not install, run, deploy, or copy its authentication/data contexts into production. Its screens, customers, keys, performance, billing and infrastructure claims are fictional and unverified.

The Express server, database JSON and environment files are prohibited. No such files were present at inspection. Obsolete server scripts have been removed; package dependencies are retained only as an inventory, not installed or approved. External image/font/link references may contact third parties if someone runs the prototype independently. No external calls were executed during this review.

Production builds and quality gates target frontend/, app/, eval/ and tests/, excluding this folder. Gitleaks continues scanning it; do not add a secret-scan allowlist. See [port plan](../design-port-plan.md) for the complete route/component/data inventory, fake assets, compatibility gaps and proposed small PRs. This step changes no frontend or backend application code.
