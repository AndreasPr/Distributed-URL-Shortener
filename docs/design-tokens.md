# Opt-in design tokens (15.12b)

Only `/design` opts into `data-design="v2"`. `/demo/design` shares the gallery implementation but deliberately retains v1, as do all other routes and the surrounding shell. No backend, dependency, authentication, proxy/CSP, next-themes, Sonner or cmdk change. No prototype imports.

## Tokens

Defined in frontend/app/globals.css, with `.dark [data-design="v2"]` overrides driven by existing next-themes:

| Family | Variables |
|---|---|
| Canvas/text | `--background`, `--foreground` |
| Surfaces | `--card`, `--card-foreground`, `--popover`, `--popover-foreground` |
| Actions | `--primary`, `--primary-foreground`, `--secondary`, `--secondary-foreground` |
| Supporting | `--muted`, `--muted-foreground`, `--accent`, `--accent-foreground` |
| Feedback/boundaries | `--destructive`, `--border`, `--input`, `--ring` |
| Radius | `--radius` (8px), `--v2-radius-control` (6px), `--v2-radius-panel` (12px) |
| Shadows | `--v2-shadow-card`, `--v2-shadow-dialog` (theme-specific) |
| Spacing | `--space-1/2/3/4/6/8/12` = 4/8/12/16/24/32/48px |
| Typography | `--font-design`, generated by next/font/local; existing type scale retained |

Blue action colors and neutral slate surfaces replace teal only inside the scope. The prototype's muted dark text and faint control borders were not copied: token tests require normal-text pairs >=4.5:1 and input/focus boundaries >=3:1. Axe tests cover actual light/dark gallery and dialog rendering; these are evidence for those states, not certification of all future combinations or disabled controls.

Inter comes from the already installed @fontsource-variable/inter WOFF2 via next/font/local, bundled into same-origin Next static assets. No package was added and no Google font download is needed. Its SIL Open Font License stays in the existing dependency. System-ui/sans-serif is the fallback. The root layout/font settings remain unchanged.

## Primitives and interaction

Existing button, badge, card, input, table, tabs, dialog and skeleton receive scoped CSS variable/slot rules; their implementations are unchanged. Radix continues to own focus trapping, Escape, tab keyboard selection and focus return. EmptyState and StatCard compose semantic HTML/existing Card; CodeBlock copies the exact text and announces success or clipboard rejection without claiming a failed copy worked. Samples are explicitly illustrative and never call the API. No PageStateSimulator changes real errors.

Portals do not inherit a page wrapper. The example DialogContent explicitly receives the same v2 attribute and font variable class on `/design` only. Menus/tooltips/Sonner remain on their existing theme and behavior; no global body attribute is toggled. Future portals must opt in explicitly, never infer a global theme from a route elsewhere.

## How later PRs opt in

After approval and contract/a11y tests, apply `data-design="v2"` and the local font variable to the smallest intended page wrapper. Do not move definitions into :root, change global shadcn defaults, or import docs/design-reference. Preserve safe existing variants and add tests for that page, portals, mobile, dark mode, auth/demo isolation and real error states. This step approves no other route for v2.
